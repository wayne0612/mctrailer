# McTrailer 安全与合规红线

本文件是硬约束，任何改动都不得违反。

## 隐私与数据
- 只读取**公开** GitHub 元数据（描述、语言、topics、最近提交信息）。**不克隆、不执行、不读取私有仓库。**
- **绝不**访问或请求用户的邮箱、电话、配送地址、账户历史订单。
- `query-nearby-stores` 需要城市/区域时，必须由**用户显式提供**，不得猜测或调用用户账户地址。

## 密钥
- MCP Token 只从环境变量 `MCD_MCP_TOKEN` 读取；**严禁**打印、写入日志、提交到仓库或展示在海报上。
- `.env` 必须加入 `.gitignore`；提交前做密钥扫描。
- 公开仓库只包含 `mcp-config.example.json`（环境变量占位符），不含任何真实 Token。

## 业务真实
- 餐品、价格、优惠、门店信息**只能**来自麦当劳 MCP 的真实响应。
- 无 Token / 请求失败 / 无门店 / 无售价时，必须降级并明确标注"演示样例 · 非实时核价"或"尚未实时核价"。
- **严禁编造**价格、营养、优惠或 Tool 成功结果。

## 操作边界
- 电影类型是**娱乐分类**，不构成对程序员技术水平的评判。
- 默认**不创建订单、不支付、不同步账户**。若未来支持，必须先获得用户明确确认。
- 不给医疗/营养/健康建议。

## 品牌与赛事合规
- 不得暗示麦当劳官方认证或背书；项目须声明为"非麦当劳官方产品"。
- 不使用未授权的麦当劳商标/素材做商业化；仅用于本次参赛演示。
- 不得刷 Star、采购 Star、互刷或以奖励诱导点赞；传播须遵守各社区规则。
- `CONTEST_DECLARATION.md` 必须为官方原文，逐字不改。
