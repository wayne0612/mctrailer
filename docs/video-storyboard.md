# 20 秒演示视频 · 分镜脚本（McTrailer 麦门导演局）

> 目标：前 3 秒抓注意力，20 秒内讲清价值并露出链接。建议 1080p、竖版或横版皆可（横版更适合 B 站/掘金，竖版适合小红书/视频号）。
> 结尾定格必须出现：演示链接 + 仓库链接 + "非麦当劳官方产品"。

## 时间轴

| 时间 | 画面 | 字幕 / 口播 | 备注 |
|------|------|------------|------|
| 0–3s | 黑屏，一行行飞快滚过的终端日志/commit 记录快速闪过 | 字幕：「改了 999 次 Bug，你的项目值得一部电影。」 | 钩子；配轻快鼓点 BGM 起 |
| 3–8s | 录屏打开演示页 `https://wayne0612.github.io/mctrailer/`，在输入框粘贴 `https://github.com/psf/requests`，点击「🎬 生成电影海报」 | 字幕：「粘贴一个仓库地址」 | 鼠标移动放慢、可加点击高亮 |
| 8–15s | 海报逐段"生长"出现：片名 → 台词 → 主角 → 今日补给餐品+价格 | 字幕：「自动判定剧情 + 麦当劳 MCP 真实菜单/价格」 | 用 media/psf-requests-poster.svg 转 PNG 做特写 |
| 15–20s | 展示完整海报，点击「⬇ 下载 PNG」，随后定格 2s | 口播+字幕：「McTrailer 麦门导演局，把你的 GitHub 项目拍成电影。开源，欢迎 Star。」 | 定格画面堆叠：演示链接 + 仓库链接 + "参赛作品·非官方产品" |

## 结尾定格要有的信息
- 在线演示：`https://wayne0612.github.io/mctrailer/`
- 开源仓库：`https://github.com/wayne0612/mctrailer`
- 角标：`麦当劳程序员节创意开发大赛 · 参赛作品 · 非麦当劳官方产品`

## 录制建议
- 工具：macOS 自带录屏（⇧⌘5）或 OBS；浏览器全屏、缩放 125%、隐藏无关标签与书签栏。
- 海报特写：把 `media/psf-requests-poster.svg` 用浏览器打开后截图/转 PNG 作穿插镜头，比纯录屏更"电影感"。
- 节奏：BGM 选轻快/电影感纯音乐；字幕大而清晰（手机可读）。
- 时长控制在 18–22s；导出 MP4。

## 合规提醒
- 不得暗示麦当劳官方认证/背书；片尾保留"非官方产品"声明。
- 不买量、不刷播放；内容真实（演示为真实可复现操作）。
